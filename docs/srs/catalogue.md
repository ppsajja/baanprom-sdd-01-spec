# Requirements Catalogue | บ้านพร้อม

ระบบ: บ้านพร้อม R1 | เวอร์ชัน: 0.9 (ร่างสุดท้ายก่อน Baseline B1) | เจ้าของ: กลุ่ม X
มาจากบทเรียน: Taxonomy, Quality และ Prioritization (รุ่นแรก) ปรับปรุงในบทเรียน Stories, Prioritization และ Modelling
